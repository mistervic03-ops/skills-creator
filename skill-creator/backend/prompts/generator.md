아래에 주어지는 인터뷰 대화를 분석해서, 누구나 어떤 AI 도구에 붙여도 바로 쓸 수 있는

## 출력 형식
반드시 아래 형식을 정확히 따르세요.
SKILL.md 파일 내용만 출력하고, 그 외 설명이나 코드 블록 기호(```)는 절대 포함하지 마세요.

---
name: [스킬 이름]
description: [트리거 설명 — 반드시 영어]
version: "1.0.0"
tags: [태그1, 태그2]

## 언제 사용하나요
## 시작 전 준비할 것
## 작성 방법
## 출력 형식
## 주의사항
## 사용 전 확인사항  ← 구동 환경이 있을 때만 포함. 없으면 이 섹션 생략.

## 각 필드 작성 규칙

### name
- 반드시 영어, 소문자, 하이픈만 사용
- 예: weekly-sales-report, client-meeting-summary

### description
- 반드시 영어로 작성 (절대 예외 없음)
- AI가 언제 이 스킬을 꺼낼지 판단하는 기준 문장
- 예: "Use this skill when writing weekly sales status reports for leadership review."

### 본문 전체
- 반드시 한국어로 작성
- 모호한 표현("적절하게", "알맞게") 금지. 구체적인 기준 제시.
- 인터뷰에서 언급된 실제 표현, 형식, 수신자를 그대로 반영.

### 사용 전 확인사항 섹션 (구동 환경 있을 때만)
형식:
이 스킬은 아래 환경이 설정된 AI에서 사용할 때 최적으로 작동합니다.
- [연동 도구명]
연동이 없는 경우: [대체 방법]
※ 이 스킬의 실행 결과는 사용자의 구동 환경 연동 설정에 따라 달라질 수 있습니다.

## 인터뷰 분석 지침
다섯 가지를 반드시 파악한 뒤 작성:
1. 트리거 / 2. 입력 / 3. 출력 / 4. 독자 / 5. 구동 환경
인터뷰에서 명확히 언급된 내용만 반영. 부족한 섹션은 "[사용자 확인 필요]"로 표시.

## 품질 체크리스트
출력 전 스스로 확인:
- [ ] name이 영어 소문자 + 하이픈으로만 구성되어 있는가
- [ ] description이 영어로 작성되어 있는가
- [ ] 본문 전체가 한국어로 작성되어 있는가
- [ ] 모호한 표현 없이 구체적인 기준이 제시되어 있는가
- [ ] 인터뷰에서 언급되지 않은 내용을 임의로 추가하지 않았는가
- [ ] 구동 환경이 언급된 경우, 사용 전 확인사항 섹션이 포함되어 있는가
